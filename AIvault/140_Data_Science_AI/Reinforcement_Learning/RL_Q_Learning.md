# RL: Q-Learning

## Definition
**Q-Learning** is a popular **model-free, off-policy Temporal Difference (TD) control algorithm** in Reinforcement Learning. Its goal is to learn an optimal [[RL_Policy|policy]] by finding the optimal action-value function, denoted as $Q(s,a)$.

>[!question]- What is the mysterious Q in Q-learning?
>The **"Q" in Q-learning stands for "Quality"** (or sometimes "Q-value").
>
>The Q-value, $Q(s,a)$, represents the **expected maximum future reward** that an [[RL_Agent|agent]] can obtain by taking action $a$ in state $s$, and then following an optimal [[RL_Policy|policy]] thereafter.
>
>Essentially, $Q(s,a)$ is a measure of "how good" it is to take a particular action $a$ when in a particular state $s$. The agent's goal is to learn these Q-values for all possible state-action pairs, which then allows it to act optimally by simply choosing the action with the highest Q-value in any given state.

## The Q-Learning Update Rule
Q-Learning iteratively updates its estimate of the optimal Q-value for a state-action pair $(s_t, a_t)$ after observing the immediate [[RL_State_Action_Reward|reward]] $r_{t+1}$ and the next state $s_{t+1}$.

$$ Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha [r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t)] $$
where:
-   $Q(s_t, a_t)$ is the current estimated Q-value for taking action $a_t$ in state $s_t$.
-   $\alpha$ (alpha) is the learning rate ($0 < \alpha \le 1$).
-   $r_{t+1}$ is the immediate reward received.
-   $\gamma$ (gamma) is the discount factor ($0 \le \gamma \le 1$).
-   $\max_{a'} Q(s_{t+1}, a')$ is the **maximum estimated Q-value for the next state $s_{t+1}$**, considering all possible actions $a'$ that could be taken from $s_{t+1}$. This is the "greedy" part of the update.
-   The term $[r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t)]$ is the **TD Error**.

## Key Characteristics
-   **Off-Policy:** This is a crucial feature. The update rule uses $\max_{a'} Q(s_{t+1}, a')$, which represents the value of the *greedy* action in the next state. This means Q-learning learns about the optimal policy *regardless* of the action actually taken ($a_t$) or the policy used to select $a_t$ (the behavior policy). This allows for learning from exploratory actions or even from historical data generated by a different policy.
-   **Model-Free:** It does not require knowledge of the environment's transition probabilities or reward function. It learns directly from experience.
-   **Value-Based:** It learns an action-value function ($Q(s,a)$) rather than directly learning a policy. The optimal policy is then derived from the optimal Q-function (choose action $a$ that maximizes $Q(s,a)$).
-   **Bootstrapping:** It updates its estimates based on the estimated value of the next state-action pair (specifically, the maximum Q-value in the next state).
-   **Convergence:** Q-learning is guaranteed to converge to the optimal Q-function under certain conditions (e.g., the environment is a finite Markov Decision Process, the agent explores all state-action pairs infinitely often, and the learning rate decays appropriately).

## Algorithm (Tabular Q-Learning)
1.  Initialize a Q-table (a matrix) $Q(s,a)$ for all state-action pairs, usually to zeros or small random values.
2.  For each episode:
    a.  Initialize state $s$.
    b.  Repeat for each step of the episode:
        i.   Choose action $a$ from state $s$ using an [[RL_Exploration_vs_Exploitation|$\epsilon$-greedy policy]] (or another exploration strategy).
        ii.  Take action $a$, observe reward $r$ and new state $s'$.
        iii. Update Q-value: $Q(s,a) \leftarrow Q(s,a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s,a)]$.
        iv.  Set $s \leftarrow s'$.
    c.  Until $s$ is a terminal state.

## Example: Simple Grid World Navigation
-   **States:** Grid cells (e.g., 0 to 15).
-   **Actions:** Up, Down, Left, Right.
-   **Rewards:** +1 for reaching goal, -1 for hitting wall, 0 for empty cell.

The Q-table would store $Q(\text{grid_cell}, \text{action})$ for all combinations. The agent would explore the grid, and for each step, update the Q-value for the action it took. Over time, the Q-values for paths leading to the goal would increase.

## Q-Learning vs. SARSA

[list2mdtable|#Q-Learning vs. SARSA]
- Feature
    - Q-Learning
        - SARSA
- **Policy**
    - **Off-policy:** Learns the optimal Q-function independent of the behavior policy.
        - **On-policy:** Learns the Q-function for the policy currently being followed (behavior policy).
- **Update Target**
    - Uses $\max_{a'} Q(s_{t+1}, a')$ (the greedy action's value in the next state).
        - Uses $Q(s_{t+1}, a_{t+1})$ (the value of the *actual action taken* in the next state).
- **Exploration**
    - Can learn the optimal policy even with a highly exploratory behavior policy.
        - The learned policy is influenced by the exploration strategy; if the behavior policy is $\epsilon$-greedy, the learned policy will be $\epsilon$-greedy optimal.
- **Risk Aversion**
    - More aggressive, can learn optimal paths that might involve risky moves if they lead to higher rewards.
        - More conservative, learns a policy that accounts for the exploration it performs, potentially finding safer paths.
- **Convergence**
    - Guaranteed to converge to optimal Q-function under conditions.
        - Guaranteed to converge to optimal Q-function if the policy converges to greedy and all state-action pairs are visited.

## Limitations
-   **Tabular Representation:** For problems with large or continuous state/action spaces, storing the Q-table becomes infeasible. This is addressed by [[RL_Deep_Reinforcement_Learning|Deep Q-Networks (DQN)]] which use neural networks as [[RL_Universal_Value_Function_Approximator_UVFA|function approximators]] for the Q-table.
-   **Exploration:** Still faces the [[RL_Exploration_vs_Exploitation|exploration-exploitation trade-off]].
-   **Convergence Speed:** Can be slow to converge for complex environments.

Q-Learning is a foundational and widely used algorithm in RL, providing a robust way to learn optimal behaviors in model-free environments.

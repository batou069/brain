# RL: Policy (on-policy vs. off-policy)

## Definition
In Reinforcement Learning, the **policy**, denoted $\pi$, is the [[RL_Agent|agent]]'s strategy for behaving in the [[RL_Environment|environment]]. It defines the mapping from observed [[RL_State_Action_Reward|states]] to [[RL_State_Action_Reward|actions]]. Essentially, the policy is the agent's "brain" or "rulebook" that tells it what to do in any given situation.

The ultimate goal of an RL agent is to learn an **optimal policy** ($\pi^*$) that maximizes the expected cumulative [[RL_State_Action_Reward|reward]] over time.

## Types of Policies
1.  **Deterministic Policy:**
    -   For a given state $s$, the policy always selects the same action $a$.
    -   Notation: $a = \pi(s)$.
    -   Example: "If in state X, always move North."
2.  **Stochastic Policy:**
    -   For a given state $s$, the policy outputs a probability distribution over all possible actions. The agent then samples an action from this distribution.
    -   Notation: $\pi(a|s) = P(A_t=a | S_t=s)$.
    -   Example: "If in state X, move North with 70% probability, East with 20%, West with 10%."
    -   Stochastic policies are crucial for [[RL_Exploration_vs_Exploitation|exploration]] (e.g., $\epsilon$-greedy policies).

## On-Policy vs. Off-Policy Learning
The distinction between on-policy and off-policy learning refers to whether the agent's learning algorithm uses the same policy to both **explore the environment** (behavior policy) and **improve its estimates** (target policy).

[list2tab|#Policy Learning Types]
- On-Policy Learning
    -   **Concept:** The agent learns about the optimal policy by evaluating or improving the **same policy** that it uses to act (explore) in the environment. The behavior policy and the target policy are the same.
    -   **How it Works:** The agent collects data by following its current policy (which is often $\epsilon$-greedy to allow for exploration). It then uses this collected data to update and improve *that very same policy*.
    -   **Characteristics:**
        -   The agent learns the value of a policy *while* following it.
        -   Often converges to a "soft" optimal policy (e.g., an $\epsilon$-greedy policy) rather than a strictly greedy one, because it accounts for the exploration inherent in its behavior.
        -   Generally simpler to implement.
    -   **Example Algorithms:** **[[RL_SARSA|SARSA]]** (State-Action-Reward-State-Action) is a classic on-policy TD control algorithm.
- Off-Policy Learning
    -   **Concept:** The agent learns about the optimal policy (the **target policy**) by evaluating or improving a policy that is **different** from the policy it uses to act (explore) in the environment (the **behavior policy**).
    -   **How it Works:** The agent collects data by following a potentially more exploratory behavior policy (e.g., a highly random policy). It then uses this data to learn about a different, often more greedy or optimal, target policy.
    -   **Characteristics:**
        -   Allows for learning about an optimal policy even from data generated by a suboptimal or random policy.
        -   Can reuse past experience (experience replay) more effectively, as the data doesn't have to come from the exact policy being learned.
        -   Often converges to a strictly greedy optimal policy.
        -   Can be more complex to implement due to the need for importance sampling or other techniques to correct for the difference between behavior and target policies.
    -   **Example Algorithms:** **[[RL_Q_Learning|Q-Learning]]** is a classic off-policy TD control algorithm. [[RL_Hindsight_Experience_Replay_HER|Hindsight Experience Replay (HER)]] is an advanced off-policy technique.

## Summary Table

[list2mdtable|#On-Policy vs. Off-Policy]
- Feature
    - On-Policy
        - Off-Policy
- **Behavior Policy**
    - Same as Target Policy
        - Different from Target Policy
- **Target Policy**
    - The policy being learned/improved.
        - The policy being learned/improved (often greedy).
- **Data Source**
    - Data generated by the current (exploratory) target policy.
        - Data generated by a separate behavior policy (can be more exploratory or even historical).
- **Learning Style**
    - "Learning while doing."
        - "Learning from observing others (or past self)."
- **Convergence**
    - Often converges to a "soft" optimal policy (accounts for exploration).
        - Can converge to a strictly greedy optimal policy.
- **Experience Replay**
    - Less effective (data quickly becomes "stale").
        - More effective (data can be reused).
- **Example Algorithms**
    - SARSA, Actor-Critic (often).
        - Q-Learning, Deep Q-Networks (DQN), DDPG.

The choice between on-policy and off-policy learning depends on the specific problem, the desired level of exploration, and the computational resources available. Off-policy methods are generally more powerful and data-efficient but can be harder to stabilize.

# Python Programming MOC 🐍

This section covers the fundamental concepts of the Python programming language, from basic syntax and data types to more advanced topics like object-oriented programming, modules, and error handling. It serves as a foundation for using Python in data science, machine learning, web development, and various other domains.

- **[[100_Python/Python_Data_Structures/_Python_Data_Structures_MOC|Data Structures]]** 🧱
  - Lists, tuples, sets, dictionaries, mutability.
- **[[100_Python/Python_Functions/_Python_Functions_MOC|Functions]]** ⚙️

  - File I/O operations, using `with` statement.
- **[[100_Python/Python_OOP/_Python_OOP_MOC|Object-Oriented Programming (OOP)]]** 🏛️

  - Error handling, `try-except` blocks, custom exceptions.

This MOC provides a structured path through core Python programming concepts. Each sub-MOC delves into specific details, keywords, built-in functions, and answers common questions related to its topic area.
